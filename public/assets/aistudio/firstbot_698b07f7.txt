5. ADD NEW VIDEO

Create two content publishing methods.

Method A: Upload Media

Allow administrator to:

- Upload MP4 files.
- Upload supported video formats.
- Enter video title.
- Add description.
- Upload thumbnail.
- Select category.
- Publish or save as draft.

Use secure object storage and resumable uploads for large files.

Method B: External Player URL

Input fields:

- Video Title
- Video Description
- Thumbnail URL
- External Player URL
- Category
- Publish Status

Example external URL:
https://playdrive.vip/e/AQGrE48AAgDqcw?stream=hd

Use a secure, provider-approved embed integration.

Validate URLs and reject unsafe schemes, private network addresses, and unauthorized sources.

Do not proxy arbitrary external URLs through the backend.

8. LIVE USER TRACKER

Create a REAL live visitor tracking system.

Admin can see:

- Currently Active Users
- Currently Watching Videos
- Total Active Sessions
- Video-wise Active Viewers
- Last Activity
- Device Category
- Browser Category

Implementation:

- Use server-side session tracking.
- Use WebSocket or Supabase Realtime.
- Send heartbeat every 20–30 seconds.
- Mark a user inactive after 60–90 seconds without heartbeat.
- Remove expired sessions automatically.

IMPORTANT:
Never use random numbers or simulated users.

Count only real active sessions. Deduplicate sessions where appropriate and explain that the number represents active browser sessions, not verified unique people.
